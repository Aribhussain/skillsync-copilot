# QP mapping accuracy

> Generated by `python ml/eval_mapping.py`. **All narratives are synthetic** (no real worker data).

Two datasets:

- **synthetic**: 60 template-generated narratives. This set is *easy* because the templates and the lexicon were written by the same team. Treat it as a sanity check, not as evidence.
- **hard**: 30 held-out, hand-written narratives (`data/eval/hard_narratives.json`). They are short, vague or misspelled, use brand names and include cross-trade traps. They were written before the first evaluation run and **not** used for tuning. Ground truth is the team's judgement, and some items are genuinely ambiguous between the four welding QPs.

Confidence is a softmax over the top-5 scores with T = 0.12.
The temperature fitted on a separate calibration split (synthetic, seed 7) is T = 0.03.

## Honest reading

- The synthetic score is inflated by construction. The hard set is the better indicator, but it is small (n = 30) and also synthetic.
- The trade-vernacular lexicon adds +13.3 points of top-3 accuracy on the hard set (ablation).
- Hard-set misses for the default engine: 3. Of these, 1 had no lexical match at all, 0 were confusions within the welding family, and 2 were cross-trade errors.
- With no lexical match the mapper sets `no_match: true` and reports 0 confidence. The UI then asks the worker to say more or pick icon cards instead of showing arbitrary QPs.
- Cross-trade errors come from shared words (e.g. 'पाइपलाइन' in a plumber's narrative) or slang the lexicon doesn't know yet (e.g. 'scooty', 'self start'). Assessor-confirmed lexicon additions are the intended fix.
- The worker and the assessor always confirm the QP, so the top-3 list matters more than top-1.
- A real evaluation needs narratives from actual RPL candidates, transcribed from speech.

## About the temperature

Fitting T on the calibration split gives T = 0.03. That split is template-generated and almost perfectly separable, so the likelihood keeps improving as T shrinks, which means maximum over-confidence. We therefore keep the pre-set T = 0.12, chosen before any evaluation. Proper calibration needs real narratives.
